# 接口契约目录（Contracts）

本目录用于记录本项目各模块之间的**接口边界、输入输出结构、行为约定与错误/状态语义**。

## 动态维护原则
- **不提前写死代码级细节**：随各编号任务推进，在真正敲定模块接口时再新增或更新对应契约文档。
- **变更即同步**：凡改动跨模块接口签名、返回字段、配置文件结构或状态语义，负责该任务的成员/Agent 必须同步更新本目录对应文档，并在 PR 中提醒组员。
